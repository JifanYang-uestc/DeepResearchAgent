- Real LLM/Tavily: not run

## Bugs Fixed

### Synchronous TODO execution

`DeepResearchAgent.run()` no longer calls an unconsumed generator. Synchronous tasks execute through
the direct `_execute_task_sync()` path, while routing and evidence collection are shared with SSE
through `_collect_task_evidence()`.

Regression coverage verifies that every TODO performs retrieval and summarization before the report
is generated, both through `run()` and `POST /research`.

### Router hard-boundary relaxation

Catalog matches no longer override a valid structured Web decision. Year expressions and the terms
`新应用`, `截至`, and `今年` are recognized as freshness signals, so a query such as
`ReAct 在 2026 年有哪些新应用？` keeps Web evidence available.

The next feature phase makes ResearchMode the authoritative source-permission boundary; the Router
remains only a Hybrid optimization surface.

### Build CLI configuration precedence

All environment-backed CLI arguments now default to `None`. Only explicitly supplied flags override
`.env`, preserving the required order: explicit CLI > environment > Configuration defaults.

### Semantic/Legacy consistency

The default HelloAgents Semantic backend no longer creates an automatic Legacy FAISS fallback.
Semantic failure therefore degrades to Web at the evidence orchestration boundary instead of reading
a potentially stale Legacy index. Legacy remains available through explicit
`KNOWLEDGE_BACKEND=legacy_faiss` or explicit dependency injection for compatibility tests.

### Failed task state

The streaming worker now sets the internal `TodoItem.status` and summary to `failed` before emitting
the safe failure event, keeping server state and frontend SSE consistent.

### Catalog file isolation

Catalog construction isolates each document. A corrupt PDF is skipped with a redacted warning while
valid TXT/Markdown/PDF entries remain available.

### Server log safety and CORS

- Exception boundary logs redact Bearer tokens, API keys, authorization values, secret tokens, and
  credentials embedded in URLs.
- Startup logging records only `api_key=configured|unset`; no token prefix/suffix is printed.
- `CORS_ORIGINS` is now consumed by FastAPI instead of using a hard-coded wildcard.
